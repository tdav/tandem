# Приёмка этапа 3

## Как запустить

- [ ] Выполнить `dotnet test Tandem.slnx`, затем `build/make-app.sh` и `build/verify-app.sh` → тесты проходят, пакет версии 0.3.0, проверка пакета выводит `RESULT: PASS`.
- [ ] Открыть `dist/Tandem.app` → две панели, меню «Инструменты» и «Сеть», настройки и вкладки предыдущих версий читаются.
- [ ] Проверить файлы `connections.json` и `known-hosts.json` в `~/Library/Application Support/Tandem/` → профили и отпечатки сохранены. Пароли и ключевые фразы доступны через «Связку ключей» в записях службы `Tandem`. Запись удаляется при удалении профиля.

## Сочетания клавиш

- [ ] На настоящей клавиатуре в обеих раскладках проверить Cmd+M, Ctrl+M, Ctrl+Shift+M, Shift+F2, Cmd+Shift+C, Cmd+Shift+D, Cmd+Shift+S, Cmd+Alt+I, Cmd+Shift+I, Cmd+K, Cmd+Shift+K, Cmd+Alt+K, Ctrl+F и Ctrl+Shift+F → команды соответствуют подписям меню и настройкам, Cmd+M открывает групповое переименование.
- [ ] С фокусом в SSH-консоли нажать Cmd+W → закрывается консоль. Cmd+M, Cmd+K, Cmd+T не управляют главным окном.

## Переименование, сравнение, синхронизация

- [ ] **Переименовать 1 000 файлов по шаблону, затем отменить** → новые и восстановленные имена совпадают с предпросмотром. Проверить счётчик, диапазон, дату, поиск, регулярное выражение и регистр.
- [ ] Попробовать имена, занятые посторонним файлом, и обмен именами → конфликты видны до запуска. Изменить один файл перед отменой → результат сообщает о пропуске.
- [ ] Сравнить папки → различающиеся и уникальные строки помечены в двух панелях. Проверить одинаковое имя в разных формах Юникода.
- [ ] Сравнить текст, двоичные файлы и файл из архива с файлом на диске → видны отличия, переход по отличиям и подсветка читаемы в обеих темах. Открыть сравнение из конфликта копирования.
- [ ] **Синхронизировать две папки** по дате и размеру, затем по содержимому → сравнение после операции показывает равенство. Проверить направления, удаление с явным выбором и подтверждением, изменение файла после предпросмотра, отмену и папку против ZIP.

## Контрольные суммы и размеры папок

- [ ] Создать и проверить CRC32, MD5, SHA-1 и SHA-256. Проверить списки от `shasum -a 256` и `md5`, изменённый и отсутствующий файл → статусы соответствуют содержимому.
- [ ] Подсчитать размер папки под курсором и всех папок → панель показывает значения и остаётся отзывчивой.

## FTP, FTPS и SFTP

- [ ] **Подключить SFTP с паролем и ключом** → просмотр, F3, копирование в обе стороны, перенос, новая папка, переименование, удаление и **F5 из открытого ZIP на сервер** работают. Проверить неверный пароль, зашифрованный ключ и изменившийся ключ узла.
- [ ] Подключить FTP и оба режима FTPS → FTP показывает предупреждение в форме. FTPS проверяет сертификат, при отказе TLS вход не происходит. Проверить кириллицу с Windows-1251.
- [ ] Создать, изменить и удалить профиль. После перезапуска открыть сохранённое подключение → сохранённый пароль считывается из связки. На локальной сети появляется системный запрос macOS.
- [ ] Во время загрузки отключить Wi-Fi и восстановить связь → повтор операции завершает передачу, файл совпадает с источником, временные файлы после успеха удалены.
- [ ] Через F4 на серверном файле изменить текст → загрузка требует подтверждения. Проверить отказ, изменение файла другим клиентом и обрыв при сохранении.
- [ ] Перезапустить программу с открытой серверной вкладкой → вкладка открывается в исходной локальной папке.

Проверки на своём сервере включаются по инструкции. [Сетевые тесты](../../tests/Tandem.Net.Tests/README.md).

## SSH-консоль

- [ ] Открыть Cmd+Alt+K с панели SFTP и с локального диска → используется сохранённый профиль. Открыть две консоли одновременно.
- [ ] **Правая кнопка с выделением копирует и снимает выделение, без выделения вставляет.** Проверить Cmd+C, Cmd+V, многострочную вставку, выделение мышью, Ctrl+C, Ctrl+D, Ctrl+R, Tab, стрелки и F-клавиши.
- [ ] Запустить `vim`, `top`, `less` или `mc`, изменить размер окна и проверить `stty size` → программа рисует текущую сетку, выход возвращает обычный экран. Проверить прокрутку, обе темы и русский текст.
- [ ] Завершить сеанс командой `exit` и отдельно оборвать связь → видны соответствующие состояния и кнопка «Подключиться снова». Закрытие живого сеанса запрашивает подтверждение.

## Известные ограничения

- ZIP на сервере открывается для чтения. Поиск по серверу и докачка не поддерживаются.
- Адреса серверов открываются через менеджер подключений. Поддерживаются пароль и закрытый SSH-ключ. Вход через `ssh-agent` и SSH-сертификаты отсутствует.
- FTP без MFMT не сохраняет время файлов. Для таких серверов можно сравнивать содержимое. У FTP остаётся интервал между проверкой свободного имени и командой переименования.
- После обрыва при отменённой операции на сервере может остаться `.tandem-part`. Правка файлов на сервере использует встроенный редактор. F3 на FTP может скачать файл целиком.
- История отмены переименования и SSH-вывод хранятся в памяти. Консоль не передаёт мышь удалённой программе, не имеет вкладок и поиска. Многострочная вставка отправляется сразу.
- Сортировка по размеру использует размеры файлов. Сборка с подписью ad-hoc может повторно запросить доступ к сохранённым паролям.
