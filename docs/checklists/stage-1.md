# Tandem — ручная приёмка этапа 1

Этот список проверяется на реальном Mac (Apple Silicon, macOS 14 или новее) на собранном `dist/Tandem.app`.
Каждый пункт — действие и ожидаемый результат. Отмечайте `[x]` то, что прошло; если что-то не так, допишите
под пунктом, что именно произошло.

Главный критерий этапа (раздел 8 спецификации): **вы целый день работаете только в Tandem вместо Finder** —
навигация, копирование, перенос, удаление в корзину, вкладки, перетаскивание, Quick Look; папка на 100 000 файлов
не тормозит; прерванное копирование не портит данные.

## Как запустить

1. Собрать приложение: в Терминале в папке проекта выполнить `build/make-app.sh`.
   Получится `dist/Tandem.app`. Скрипт каждый раз собирает пакет заново.
2. Проверить сборку: `build/verify-app.sh`. Каждая проверка печатает PASS / FAIL; в конце должно быть
   `RESULT: PASS`. Пробный запуск внутри проверки пропускается (SKIPPED), если экран спит, — это не ошибка.
3. Запустить: двойной щелчок по `dist/Tandem.app` в Finder или `open dist/Tandem.app`.
4. Где что лежит:
   - настройки, вкладки, избранное, положение окна: `~/Library/Application Support/Tandem/state.json`;
   - журнал непредвиденных ошибок: `~/Library/Logs/Tandem/tandem.log` (при нормальной работе файла нет или он пуст).
5. Как сбросить настройки: закрыть Tandem и удалить папку `~/Library/Application Support/Tandem`
   (или переименовать её, чтобы сохранить копию). При следующем запуске всё будет как после установки.
6. Необязательно, один раз: `build/create-dev-cert.sh`. Скрипт создаёт в вашей связке ключей входа
   самоподписанный сертификат «Tandem Local Dev» для подписи программ. Зачем: macOS запоминает выданные Tandem
   разрешения на папки (Рабочий стол, Документы, Загрузки, флешки, сетевые диски) по подписи приложения. Без
   сертификата каждая пересборка получает новую подпись, и macOS спрашивает разрешения заново. С сертификатом
   подпись постоянная. **Без него всё работает**, просто вопросы о доступе повторяются после каждой сборки.
   Скрипт перед изменениями объясняет, что добавит, и просит ввести `yes`; удалить сертификат потом можно
   командой `security delete-identity -t -c "Tandem Local Dev" ~/Library/Keychains/login.keychain-db` или в
   «Связке ключей» (вход → Мои сертификаты → Tandem Local Dev → Удалить). После создания сертификата
   выполните `build/make-app.sh` ещё раз.

## Запуск и окно

- [ ] Двойной щелчок по `dist/Tandem.app` → открывается окно с двумя панелями, в Dock значок приложения
      (пока стандартный, своего значка нет), в строке меню «Tandem», «Файл», «Выделение», «Переход», «Вид», «Окно».
- [ ] Закрыть окно → приложение завершается; в `~/Library/Logs/Tandem/tandem.log` нет новых записей.
- [ ] Перевести Mac в сон экрана (горячий угол «Выключить дисплей» или закрыть крышку MacBook при подключённом
      внешнем мониторе), разбудить, запустить Tandem сразу после пробуждения → приложение стартует. Отдельно: добавить Tandem в
      «Объекты входа» (Системные настройки → Основные → Объекты входа), перезагрузиться → после входа Tandem
      открылся. Если при спящем экране приложение не стартует (известная особенность, см. ограничения), запишите,
      появилось ли окно после пробуждения экрана.
- [ ] Первая попытка открыть «Документы» или «Рабочий стол» → macOS спрашивает разрешение; после «Разрешить»
      папка открывается. При отказе — понятное сообщение в панели, а не падение.
- [ ] Защищённая папка без доступа (например `~/Library/Mail`) → сообщение «Нет доступа к папке…» с подсказкой,
      приложение работает дальше.

## Навигация и панели

- [ ] Tab → активной становится другая панель, выделение активной панели хорошо видно.
- [ ] Enter на папке → вход в неё; Enter на файле → файл открывается программой по умолчанию.
- [ ] Backspace (и Cmd+↑) → переход в родительскую папку, курсор стоит на папке, из которой вышли.
- [ ] Строка с `..` вверху списка → Enter на ней поднимает на уровень выше.
- [ ] Cmd+Shift+G → путь можно ввести вручную; Enter переходит, Esc отменяет; несуществующий путь → сообщение.
- [ ] Столбцы: имя, расширение, размер, дата, права. Щелчок по заголовку → сортировка по нему, повторный щелчок →
      в обратном порядке; у заголовка видна отметка направления.
- [ ] Сортировка с клавиатуры в активной панели: Ctrl+Cmd+1 → по имени, Ctrl+Cmd+2 → по расширению, Ctrl+Cmd+3 →
      по размеру, Ctrl+Cmd+4 → по дате; то же сочетание ещё раз → обратный порядок; Ctrl+Cmd+R → обратный порядок
      по тому же столбцу. Отметка ▲/▼ у заголовка меняется, курсор остаётся на том же файле, другая панель не
      меняется. Проверить и на русской раскладке.
- [ ] Меню «Вид → Сортировка»: «По имени», «По расширению», «По размеру», «По дате» и «В обратном порядке», у
      каждого пункта видно сочетание; отмечен столбец активной панели и, если порядок обратный, «В обратном
      порядке». После Tab (другая панель) и после переключения вкладки отметки показывают её сортировку. Выбор
      пункта меню сортирует так же, как сочетание.
- [ ] Набор букв в панели → курсор переходит на первое подходящее имя (быстрый поиск); буквы не попадают в
      командную строку.
- [ ] Создать/удалить файл в показанной папке из Finder или Терминала → панель обновляется сама за секунду.
- [ ] Cmd+R → панель перечитывает папку.
- [ ] Cmd+U → панели меняются местами; Cmd+Shift+U → в другой панели открывается та же папка.
- [ ] Cmd+Shift+. → скрытые файлы появляются; повтор → скрываются. Отметка в меню «Вид → Скрытые файлы»
      соответствует состоянию.
- [ ] Строка состояния под панелью показывает «Выбрано N из M, объём»; цифры меняются при выделении.

## Выделение

- [ ] Пробел → элемент выделяется цветом, курсор идёт вниз; повтор на выделенном → снимает выделение.
- [ ] Shift+↓ / Shift+↑ → выделяет элементы по пути курсора.
- [ ] Cmd+A → выделено всё (кроме `..`).
- [ ] Cmd+= → окно маски; `*.pdf` → выделены все PDF. Cmd+- → снимает выделение по маске.
- [ ] Cmd+Shift+A → выделение обращается (невыделенные становятся выделенными и наоборот). Проверить, что
      сочетание не перехватывает служба macOS (в некоторых системах Cmd+Shift+A занята «Службами», например
      «Поиск в man-страницах в Терминале»): если вместо обращения выделения открылось что-то другое — запишите.

## Тома и боковая панель

- [ ] Над каждой панелью строка томов со свободным местом («свободно X из Y»); щелчок по тому → переход в него.
- [ ] Вставить флешку → том появляется в списке за несколько секунд; извлечь → исчезает.
- [ ] Подключить образ диска (двойной щелчок по `.dmg`) → том появляется; «Извлечь» → исчезает.
- [ ] Подключить медленный сетевой диск (SMB, «Подключение к серверу» Cmd+K в Finder) → том появляется, окно
      не замирает, пока сеть отвечает медленно; отключить → том исчезает.
- [ ] Извлечь том, папка которого открыта в панели → приложение не падает; запишите, что показывает панель.

## Вкладки, избранное, история

- [ ] Cmd+T → новая вкладка с той же папкой и той же сортировкой (дубликат текущей); Cmd+W → закрывает её;
      последнюю вкладку закрыть нельзя.
- [ ] Крестик на вкладке → закрывает именно эту вкладку; активная вкладка остаётся активной (если закрыли не её).
- [ ] Ctrl+Cmd+P → активная вкладка закреплена: на ней значок булавки, крестика нет. Cmd+W, пункт меню
      «Окно → Закрыть вкладку» (он недоступен) и «Закрыть остальные» её не закрывают; сообщений об ошибке нет.
      Повтор Ctrl+Cmd+P → вкладка откреплена, крестик вернулся. В меню «Окно» пункт называется «Закрепить
      вкладку» или «Открепить вкладку» по состоянию активной вкладки.
- [ ] Правый щелчок по вкладке (в том числе в неактивной панели) → сначала эта вкладка и её панель становятся
      активными, затем меню: «Новая вкладка», «Дублировать», «Закрепить» (у закреплённой — «Открепить»),
      «Закрыть», «Закрыть остальные»; рядом видны сочетания (Cmd+T, Ctrl+Cmd+P, Cmd+W); недоступные пункты
      серые (например «Закрыть» у закреплённой или единственной вкладки).
- [ ] «Дублировать» → рядом открывается вкладка с той же папкой. «Закрыть остальные» → в этой панели остаются
      только вкладка, по которой щёлкнули, и закреплённые; вкладки другой панели не меняются.
- [ ] Ctrl+Tab / Ctrl+Shift+Tab → переключение вкладок; щелчок по вкладке → тоже.
- [ ] У каждой вкладки своя папка, своя сортировка и своя история.
- [ ] Cmd+D → меню избранного; «Добавить текущую папку» → папка в списке; выбор → переход; «Убрать текущую
      папку» → исчезает.
- [ ] Cmd+[ / Cmd+] (и кнопки «Назад» / «Вперёд») → переходы по истории панели.
- [ ] Правый щелчок по кнопке «Назад»/«Вперёд» → список посещённых папок; выбор → переход.
- [ ] Долгое нажатие на «Назад»/«Вперёд» → тоже открывается список истории, и при этом НЕ выполняется лишний
      переход назад (обычный щелчок не должен сработать в придачу к долгому нажатию).

## Копирование и перенос

- [ ] F5 (или Cmd+5) на файле → диалог с путём к другой панели; Enter → файл скопирован, обе панели обновились.
- [ ] F6 (или Cmd+6) → перенос; файл исчез из исходной папки и появился в целевой.
- [ ] Копирование при совпадении имени → вопрос: заменить / пропустить / переименовать (и «Применить ко всем»);
      ничего не заменяется молча.
- [ ] Копирование папки с вложенными папками → структура и содержимое совпадают.
- [ ] Перенос между томами (например на флешку) → сначала копирование, исходные файлы удаляются только после
      успешной копии.
- [ ] Копирование большого файла на другой том (на одном томе APFS копия мгновенная и окно прогресса не успевает
      появиться — берите флешку или образ диска, см. ниже) → появляется окно прогресса: файлы N из M, байты,
      скорость, оставшееся время.
- [ ] В окне прогресса посреди большого файла «Приостановить» → сразу вместо неё доступна «Продолжить»,
      состояние становится «Приостановлено», счётчик байтов перестаёт расти; «Продолжить» → идёт дальше;
      результат совпадает с исходным файлом (можно сравнить `cmp исходный копия`).
- [ ] «Приостановить» и сразу «Продолжить» (запрос отозван) → копирование не останавливается, кнопки не
      «зависают».
- [ ] «Приостановить», затем «Отменить» → копирование отменено, в папке назначения нет `.имя.tandem-part`.
- [ ] «В фон» → окно прогресса скрывается, копирование продолжается, можно работать в панелях.
- [ ] «Отменить» посреди файла → в папке назначения НЕТ ни частичного файла под настоящим именем, ни временного
      `.имя.tandem-part` (проверить с показом скрытых файлов, Cmd+Shift+.).
- [ ] Выдернуть флешку во время копирования на неё → понятное сообщение об ошибке, приложение не падает, на
      исходном диске всё цело; после повторного подключения на флешке нет файла под настоящим именем
      (допустим только недописанный `.имя.tandem-part`, если система не успела его удалить).
- [ ] Копирование на флешку exFAT (или образ exFAT, см. ниже) файлов с тегами Finder и расширенными атрибутами
      (например файлы, скачанные из интернета) → копирование проходит; если возникла ошибка про атрибуты или
      метаданные — запишите текст ошибки и имя файла.
- [ ] То же на сетевой диск (SMB) → копирование проходит или выдаёт понятную ошибку; запишите, если ошибка про
      атрибуты.

Как сделать тестовый том и большой файл без флешки (всё в домашней папке, удаляется в конце):

```sh
# образ exFAT на 6 ГБ и большой файл 4 ГБ со случайными данными
hdiutil create -size 6g -fs ExFAT -volname TandemExFAT ~/TandemExFAT.dmg
hdiutil attach ~/TandemExFAT.dmg            # появится том /Volumes/TandemExFAT
dd if=/dev/urandom of=~/tandem-big.bin bs=1m count=4096
# ... проверки ...
hdiutil detach /Volumes/TandemExFAT
rm ~/TandemExFAT.dmg ~/tandem-big.bin
```

## Удаление, корзина, переименование, новая папка

- [ ] F8 (или Cmd+Backspace) → вопрос «Переместить … в Корзину?»; подтвердить → элемент в Корзине.
- [ ] В Finder открыть Корзину → у удалённого элемента есть «Вернуть»; после «Вернуть» он на прежнем месте, и
      панель Tandem это показывает.
- [ ] Shift+F8 (или Cmd+Option+Backspace) → вопрос «Удалить … безвозвратно?» с текстом «Это действие нельзя
      отменить»; кнопка по умолчанию — «Отменить» (нажатие Enter НЕ удаляет).
- [ ] F7 (или Cmd+7) → имя новой папки; Enter → папка создана, курсор на ней; имя занято → сообщение.
- [ ] Shift+F6 (или F2, Cmd+Shift+R) → переименование прямо в списке; Enter сохраняет, Esc отменяет.
- [ ] Переименовать папку, меняя только регистр букв (`photos` → `Photos`) → папка переименована, содержимое
      на месте, ничего не потеряно.
- [ ] Начать переименование в списке и, не завершая, создать файлы в этой же папке из Терминала
      (`touch a b c`) → поле переименования не пропадает и не переезжает на другой файл; Enter переименовывает
      именно тот файл.

## Перетаскивание

- [ ] Перетащить файл из Finder в панель Tandem → диалог с тремя кнопками «Копировать», «Перенести»,
      «Отменить»; выбранное действие выполнено; без подтверждения ничего не происходит.
- [ ] Перетащить файл из панели Tandem в окно Finder (или на Рабочий стол) → файл скопирован туда.
- [ ] Перетащить из одной панели Tandem в другую → тот же диалог из трёх кнопок; «Перенести» переносит.
- [ ] Перетащить на папку внутри панели → цель — эта папка (она подсвечивается под курсором).
- [ ] Перетащить с зажатой Cmd → запишите, что произошло: принимается ли перетаскивание вообще, и какая кнопка
      выбрана в диалоге по умолчанию (ожидается: диалог появляется; «Перенести» может быть выбрана заранее).
- [ ] «Отменить» в диалоге → ничего не изменилось ни в источнике, ни в цели.

## Интеграция с macOS

- [ ] Cmd+Y → Quick Look выбранного файла; движение курсора стрелками → Quick Look показывает новый файл;
      повторное Cmd+Y → закрывается.
- [ ] F3 (Cmd+3) → Quick Look; F4 (Cmd+4) → файл открывается в системном редакторе (см. ограничения).
- [ ] Правый щелчок на файле → «Открыть в» → список подходящих программ; выбор → файл открыт в ней.
- [ ] «Показать в Finder» (меню «Файл» или правый щелчок) → Finder открывается с выделенным файлом.
- [ ] «Открыть в Терминале» / «Открыть терминал здесь» → Терминал в текущей папке панели.
- [ ] Cmd+I → «Свойства»: размер, дата, владелец (только просмотр), права (чтение/запись/выполнение для
      владельца, группы, остальных и восьмеричное значение).
- [ ] Изменить права (например снять «Запись» у группы) и «Применить» → в Терминале `ls -l` показывает новые
      права; столбец «Права» в панели обновился.
- [ ] Ввести неверное восьмеричное значение (`999`) → подсказка «Введите три восьмеричные цифры…».
- [ ] Теги в свойствах: добавить `Работа, Важное` → в Finder у файла эти теги; удалить тег в Finder → в
      свойствах Tandem он тоже пропал.

## Командная строка

- [ ] Cmd+L или щелчок → фокус в командной строке; Esc → фокус обратно в панель.
- [ ] `cd ~/Downloads` → активная панель переходит в «Загрузки»; `cd ..` → вверх; неверный путь → сообщение.
- [ ] `ls -la` → вывод появляется во всплывающей области «Вывод», в конце «Команда завершена с кодом 0».
- [ ] `yes | head -c 50000000` → окно остаётся отзывчивым (панели прокручиваются, меню открываются), вывод
      ограничен последними строками, есть пометка «Более ранний вывод удалён»; через несколько секунд команда
      завершается.
- [ ] Длинная команда (`sleep 20`) → «Прервать» останавливает её; появляется «Команда прервана».
- [ ] `sleep 30 &` → командная строка сразу снова доступна (не зависает); фоновая команда продолжает работать
      (см. ограничения) — проверить в Терминале `pgrep -fl "sleep 30"`.
- [ ] «Очистить» → вывод очищен; «Закрыть» → область вывода скрыта и сама больше не открывается, пока не
      запустите новую команду.

## Клавиатура

- [ ] F-клавиши работают с Fn (или при включённом «Использовать F1, F2 и т. д. как стандартные функциональные
      клавиши»); у каждой команды с F-клавишей есть второе сочетание с Cmd (см. меню).
- [ ] Переключить раскладку на русскую и повторить: быстрый поиск русскими буквами находит русские имена;

## Большие папки

Создать тестовую папку на 100 000 пустых файлов во временной папке:

```sh
D="${TMPDIR:-/tmp}/tandem-100k"
mkdir "$D" && cd "$D" && seq -f 'file-%06.0f.txt' 1 100000 | xargs touch && cd - && echo "$D"
```

- [ ] Перейти в эту папку (Cmd+Shift+G и путь, напечатанный командой) → список появляется меньше чем за секунду,
      окно не замирает.
- [ ] Прокрутка колесом, трекпадом, PageUp/PageDown, Home/End → плавно, без рывков.
- [ ] Cmd+A, затем Cmd+Shift+A → выделение быстро меняется; строка состояния показывает 100 000.
- [ ] Быстрый поиск (`file-09`) → курсор сразу переходит.
- [ ] Удалить тестовую папку (не через Корзину, а командой в Терминале):
      `rm -rf "${TMPDIR:-/tmp}/tandem-100k"` → команда завершается без сообщений; `ls "${TMPDIR:-/tmp}/tandem-100k"`
      отвечает «No such file or directory». Если папка была открыта в панели, Tandem не падает и за пару секунд
      показывает ближайшую существующую родительскую папку.

## Известные ограничения этапа 1

- Команды, запущенные в командной строке в фоне (`команда &`), продолжают работать и после завершения
  команды, и после закрытия Tandem — как в обычном терминале. Остановить их можно в Терминале или «Мониторинге
  системы».
- Пока копирование приостановлено (в том числе посреди большого файла), копируемый и недописанный файлы
  остаются открытыми: флешку в это время нельзя извлечь. Продолжите или отмените копирование, затем извлекайте.
  Копирование в пределах одного тома APFS мгновенное (клон файла) — там приостанавливать нечего.
- После перетаскивания всегда появляется вопрос «Копировать или перенести» — даже если при перетаскивании была
  зажата клавиша. Источнику перетаскивания (например Finder) всегда сообщается «скопировано», поэтому Finder
  сам ничего не удаляет.
- F3 открывает Quick Look, F4 — файл в системном редакторе. Встроенные просмотр и редактор появятся на этапе 2.
- Своего значка у приложения пока нет (будет на этапе 4).
- Смена языка применяется только после перезапуска.
- Если экран спит (например при запуске сразу после входа или удалённо), приложение может не запуститься:
  графическая подсистема не может стартовать без включённого дисплея. Включите экран и запустите снова.
- Без сертификата «Tandem Local Dev» macOS заново спрашивает разрешения на папки после каждой пересборки.
- Копирование на тома, не умеющие хранить расширенные атрибуты macOS (exFAT/FAT, некоторые сетевые диски), может
  завершиться ошибкой на файлах с такими атрибутами; это и проверяется пунктами выше.
- Панели кнопок с пользовательскими командами, поиска файлов, архивов, настройки клавиш и сетевых подключений
  пока нет (этапы 2–3).
